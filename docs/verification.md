# 验收清单

功能列表不是验收结果。本页说明每项需求如何验证，版本发布应同时记录源码版本、测试结果和实际运行状态。

## 自动回归

在仓库根目录运行：

```bash
python3 scripts/check_release.py --indexed
docker build --target test -t qq-tmux-relay-test .
docker run --rm --network none qq-tmux-relay-test
```

测试使用独立tmux socket和可销毁会话，不操作现有工作窗格。QQ接入和额度上游使用可控响应，不向真实聊天发消息、不刷新私人账号。

| 需求 | 验证要点 |
| --- | --- |
| 一个bot同时连接多个终端 | 两编号各自的来源、基线、待发队列与退出互不影响 |
| 本地与SSH远端 | 统一列表、严格指纹、远端失败提示、本机仍能用 |
| 永久001–999 | 重启不变、同名新窗格不复用、999后拒绝分配 |
| sel与操作模块换序 | ent/ext/key/type/send/tail两种顺序；任意正文不误识别目标 |
| tail N替代list100 | 1–5000校验、原始快照不清洗、旧指令不误输终端 |
| 键盘映射 | 字符/符号/F键/编辑键/组合键及真实tmux输入字节 |
| 新输出自动追加 | 进入运行中任务后无需再次输入；按正文段落投递而非逐行 |
| 清洗与完整菜单 | 工具/diff/搜索/折叠噪音隐藏，菜单完整，429/5xx和Worked保留 |
| 双方静默30分钟 | 成功输出也续期，采样和失败发送不算互动，超时只断当前连接 |
| 互斥与恢复 | 同窗格跨实例租约，状态恢复、收据去重和失败队列 |
| 文件上传/下载/清理 | 本人授权先于下载；验证宿主缓存身份；仅删除登记缓存 |
| 额度及积分 | 强制刷新和新鲜度，8格进度条，积分精度，真实错误不显示成0 |
| 帮助与QQ指令面板 | /help与模块帮助不输入终端，面板只改本人作用域 |
| 仓库和发布 | 凭据/状态不进Git，公开部署文件可初始化，保留许可证 |

## 真实远端测试

已有可信SSH别名时，可以运行：

```bash
python3 scripts/smoke_remote.py --ssh-alias research
```

它会在本地和指定远端创建自己的临时tmux服务器，验证中文和特殊字符原样输入、多个通道及独立退出，结束后只清理自己的会话。先确认别名确实指向预期服务器，不在真实工作窗格中发送测试命令。

## QQ上线验收

测试通过后，还需在自己的bot确认：本人私聊和绑定群能接入；进入后不发新消息也能收到新增文本；/file help、/help、文件上传路径、下载和缓存清理正常；额度失败显示错误；原来绑定和进度保留；废弃实例停止。

容器健康或HTTP200仅证明部分链路。应检查官方QQ发送返回的消息ID，并在手机上验收排版、文件可下载和群权限。官方回执、真实终端操作、模拟单元测试和手机客户端验证是不同证据，不应互相代替。
