## 指令帮助

- `/help`：全局功能总览。
- `/tmux help`：终端模块详细操作。
- `/file help`：文件下载、缓存清理与权限说明。

终端、文件和额度由同一个bot处理，但文件/额度不会输入任何终端。各功能不经过模型处理，权限和数据由当前实例独立维护。

## 目录约定

`src/`放运行代码，`tests/`放回归，`scripts/`放维护脚本，`deploy/`只放公开部署示例，`vendor/`放上游适配器及许可，`docs/guide/`放离线助手。初始化生成的真实凭据、绑定、状态和备份只放`instances/`等忽略目录，不属于文档或公开源码。
