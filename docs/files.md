# 文件收发

`/file help`查看文件指令和权限；`/help`查看终端、文件与额度功能总览。

同一个终端bot承担文件、图片、语音上传和本机文件下载，不调用模型、不识图、不转写。
本人私聊可直接发；群内仍要求绑定本人的@事件。普通群文件上传没有QQ官方事件时无法自动监听全群网盘，请在机器人消息中携带附件并@它。

## 上传

发文件后收到“接收完成”和服务器绝对路径。路径不会自动输入任何tmux，你可以明确选择目标：

```text
/tmux sel 001 请读取 /服务器返回的绝对路径/文件.zip
```

文件在实例数据目录的cache中，不要求已连接终端。宿主与容器通过相同inode核验挂载，校验失败会提示接收失败，而不是提供不存在的路径。
多窗格和跨聊天不猜测目标。路径属于运行bot的本机，在SSH远端不可直接使用，需你另行scp或其他传输。

## 下载

```text
/file dl /home/alice/project/result.zip
```

仅本机绝对路径、桥接用户可读取的普通文件，最多100 MiB。目录、设备、FIFO、最终路径符号链接和传输时正在变化的文件会拒绝。
桥接先创建权限600的有限大小快照，QQ容器只读取自身挂载中的快照，不挂载整个宿主工作区。
发送完成或失败后清理临时快照；QQ限额或上传失败返回错误，不假称下载成功。平台实际资格、单文件/日额度仍可能限制发送。

## 清理

```text
/file rm
/file rm /home/alice/bot/data/cache/documents/upload.txt
```

不带路径时清理全部登记的上传缓存；带路径时只清理指定的已登记缓存。仅删除仍对应原inode的文件，不清空/tmp、不删除任意目录、不删除项目文件。清理后原路径失效，请先让终端读取或转存。
文件命令独立于sel连接，不改选中窗格、不延长某个终端连接的静默时间。这里没有消息下方快捷按钮，统一手动指令。

## 权限

只有绑定本人可以请求文件操作；群下载对全群可见。桥接普通用户的可读权限就是下载边界，没有额外的工作区限制；不要把敏感文件发送到群。
SSH配置、密钥和真实缓存不进Git。每个实例独立保存AppID、绑定和缓存数据，文件操作不改变终端连接。
