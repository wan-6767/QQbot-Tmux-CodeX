# 使用手册

## 一个 bot，多台服务器，多条终端连接

私聊直接发送；群里每条指令都 @当前 bot：

```text
/tmux ls
/tmux sel 001 ent
/tmux sel 002 ent
/tmux sel 001 检查这个项目的测试结果
/tmux sel 002 /model
/tmux sel 002 key down
/tmux sel 002 key enter
/tmux sel 001 list100
/tmux sel 001 ext
```

`ls` 按服务器分组，`local` 是本机，远程名称由配置决定。编号001–999持久化对应真实窗格，不是列表排序。重排、改名、正常重启不改编号；关闭或替换的窗格不会复用旧编号。所有窗格均可获得编号。

回显标注 `[001 · local · work:0.0]` 或 `[012 · research · train:0.1]`。每个编号独立拥有连接、发送目的地、增量基线、失败队列和计时；退出001不影响002，不停止终端任务。

## 指令速查

| 指令 | 行为 |
| --- | --- |
| `/help`、`/tmux help` | 全部帮助 |
| `/tmux ls` | 本地及远程窗格、固定编号、连接及占用状态 |
| `/tmux sel 001 ent` | 接入，先返回最近约100行，再持续追加 |
| `/tmux sel 001 文字` | 原样输入并回车 |
| `/tmux sel 001 /model` | 交给指定终端的程序命令 |
| `/tmux sel 001 type 文字` | 输入但不回车 |
| `/tmux sel 001 key enter` | 回车确认 |
| `/tmux sel 001 key up` | 方向键，每次一键 |
| `/tmux sel 001 send ent` | 将保留词ent当普通文字发送 |
| `/tmux sel 001 list100` | 原始100行快照，只重置这一连接的追加进度 |
| `/tmux sel 001 ext` | 仅断开这一连接，任务继续运行 |
| `/group bind`、`/group status`、`/group unbind` | 私聊管理群绑定 |

按键：`enter`、`esc`、`up`、`down`、`left`、`right`、`tab`、`space`、`backspace`、`delete`、`home`、`end`、`pgup`、`pgdn`、`ctrl-c`、`ctrl-d`。不支持重复次数及任意组合键。`ctrl-c`可能中断任务，`ctrl-d`可能结束程序。

`ent`是接入，回车是`key enter`；`ext`是断开，不是退出程序。`ent/ext/list100`以及带参数的`key/type/send`是保留操作；作为文字输入时加`send`前缀。

新版不再执行旧`/tmux select 1`、`/tmux exit`、无编号普通文字或裸`/model`，避免发进错误终端。所有终端输入必须有编号，公开指令统一以`/`开头。

## 自动追加和原始快照

进入时任务已经运行，也会持续追加，无需再发消息触发。正文和代码示例按完整段落转发，合并终端宽度导致的软换行；保留429/5xx错误及`Worked for ...`结束字段。工具操作、diff和折叠日志只在`list100`原始快照中出现。模型/权限/确认菜单整体回显，不只发光标改变的几行。

超长文本用一个完整`.txt`附件，不逐行拆分、不静默截断。QQ拒绝投递时保留队列并退避，重启补发未确认的段落；QQ已接受但客户端丢失回执时不能保证严格恰好一次。屏幕采样不是程序原生消息流，极快且完全相同的答案、未知TUI可能无法正确识别，有疑问用原始快照核对。

每个编号单独计算静默：本人输入或成功投递的新输出续期；双方30分钟无消息才断开。轮询、隐藏日志和其他编号的消息不续期。重连用原编号`ent`；如果窗格已关闭，先重新`ls`。

输入或SSH超时先`list100`核对，不能据报错认定输入未执行，不能盲目重发。输入收据全局去重，避免同一QQ事件因重试发往不同编号。

## 私聊、群聊和权限

同一编号只能绑定一个聊天目的地，不能同时转发到私聊和群聊。切换前在原聊天`ext`，其他编号不受影响。每个AppID的QQ OpenID独立；多个bot仍通过共享内核锁避免同时占用同一真实窗格。

群里只有绑定本人的@消息可以输入，但输出全群可见。所有窗格共用一个QQ发送额度管理器，窗格变多不增加平台限额；被动窗口耗尽后仍需QQ允许主动消息，服务器不能绕过。修改群绑定前退出该群全部连接。

工具不调用模型，不提供上传下载、额度、日记或计划。图片、语音、附件不会输入终端，不下载。终端自身有多少权限，绑定QQ就能使用多少权限。

远程接入见[SSH配置](remote.md)。远端暂时不可达会在列表显示诊断，本机仍可用，远程编号保留。
